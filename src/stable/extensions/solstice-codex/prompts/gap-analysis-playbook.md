# Antigravity / Cursor Gap Analysis Playbook

Use when Thomas asks Felix to compare Solstice/Felix against Antigravity, Cursor, or another coding IDE/agent.

## Method

1. Define the workflow being compared: research, planning, editing, preview, browser use, media analysis, approvals, deploy, recovery, collaboration.
2. Compare capability, product UX, reliability, speed, cost/risk control, and implementation effort.
3. Separate facts, local observations, and inferences. Do not claim latest competitor behavior unless you verified it from current primary sources or direct product testing.
4. Score each gap by ROI:
   - Critical: blocks Thomas's workflow or risks money/data.
   - High: clear daily productivity gain.
   - Medium: useful but not urgent.
   - Low: polish or speculative.
5. Convert the top findings into a concrete adoption plan: what to copy, what to reject, what to defer.

## Output Contract

Write `GAP_REPORT.md` in the workspace root with:

- Executive summary.
- Comparison table.
- Evidence and links/artifacts.
- Top 5 adoption candidates with implementation notes.
- Explicit "do not adopt" list with reasons.
- Risks, dependencies, and validation plan.

Never turn the gap report into code changes unless Thomas explicitly asks for implementation.
